# Zackary Weissman-Bennett — Engineering Portfolio

Personal engineering portfolio featuring CubeSat mechanical development, motor fault detection, OTEC structural research, and an FDM bridge project.

## Edit the site

The complete page, styling, and project content are in `index.html`. Images and the résumé PDF are in `assets/`. No build step or dependencies are required.

## GitHub Pages

In Settings → Pages, choose **Deploy from a branch**, select **main**, and select **/(root)**. Save to publish the site.
